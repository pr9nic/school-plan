Печать горизонтального А3 из листов А4

  1. Печатайте в масштабе 100%, без «Вписать в страницу». На первом листе есть отрезок 100 мм: сверьте его линейкой.
  2. У следующего листа отрежьте белое поле по пунктиру.
  3. Намажьте штрихованную полосу клеем и наложите лист так, чтобы рисунок совпал.
  4. Белые края готового плаката обрежьте по тонкой линии.
