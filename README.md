# Верстальщик планов

Программа для вёрстки школьного плана недели. Работает прямо в браузере, ничего устанавливать не нужно.

## Как пользоваться

1. Нажмите на любой текст на плане и измените его. Макет обновляется сразу.
2. Кнопка «+» добавляет событие в день, стрелки вверху переключают недели. Дни без событий на план не попадают: они ждут в строке «Нет на плане» под макетом.
3. Переключатель вверху показывает план как горизонтальный лист А3 или как картинку для VK (1080×1920). «Скачать картинку» сохраняет PNG в выбранном виде.
4. «Печать А3» собирает PDF для склейки горизонтального А3 из листов А4: 2 листа дают почти А3, 4 листа дают ровно А3 с обрезкой.

Планы хранятся в браузере на этом компьютере и никуда не отправляются. Чтобы передать план коллеге или на другой компьютер, в меню «Ещё» выберите «Сохранить план файлом», а там «Открыть файл плана».

## Для разработчика

Страница собирается в один файл `index.html`:

```
python src/build.py
```

Исходник лежит в `src/index.src.html`, картинки в `src/alisa`, стартовый план в `src/example-plan.json`.
